Why Chrome SEO extensions work when a website tool fails Extensions can read the page you already opened. A webpage on GitHub Pages cannot freely download protected sites (CORS / bot walls). For blocked URLs, install the extension below or paste page source.

Analyzes title, meta, H1, canonical, images, internal & outbound links. True inbound backlinks need a CSV upload below.

Best option: Chrome extension (works like other SEO extensions)
  1. Download the portfolio repo and open the chrome-seo-analyzer folder
  2. Chrome → chrome://extensions → enable Developer mode
  3. Click Load unpacked → select chrome-seo-analyzer
  4. Open the site in a tab → click the extension → Analyze this page

Full steps: see chrome-seo-analyzer/README.md in the project.

Site blocked? Paste page HTML instead

On the website: right-click → View Page Source → Ctrl+A → Ctrl+C, then paste below and click Run SEO analysis. Do not paste only the URL.
