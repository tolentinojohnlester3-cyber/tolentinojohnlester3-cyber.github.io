How llms.txt helps AI cite your site

llms.txt does not move your Google rankings. It is a plain-text file at the site root that tells ChatGPT, Gemini, Perplexity, and Copilot who you are, which facts are canonical, and which URLs to quote. That is how you “rank” inside an AI answer: the model can attribute you without guessing.

What llms.txt is (and is not)

llms.txt is a proposed convention: a Markdown-ish text file at https://yoursite.com/llms.txt that large language models can fetch when they need a short, official map of the site. Think of it as a sitemap written for a reader that prefers paragraphs over XML. This portfolio’s live file is at /llms.txt.

It is not a Google ranking signal. Google still ranks HTML pages using crawl, links, content, and experience. Shipping llms.txt will not recover a spam-hit site or replace classic SEO. Google already has robots.txt, sitemaps, and structured data for that job.

Working definition: llms.txt is a GEO file — a canonical cheat sheet so a generative engine can lock your entity and pick the URLs you want cited. Pair it with crawlable pages. A txt file with nothing behind it is a brochure nobody can verify.

It sits in layer 3–4 of the layers of SEO stack: GEO (get cited) and AIO (make the entity machine-readable). AEO still owns snippets. Do not skip those layers and expect a 40-line file to do the rest.

How it helps you “rank” in AI answers

People now ask models the questions they used to type into Google. The model writes an answer from retrieval, tools, and memory. If your facts are scattered — “SEO manager” on LinkedIn, “CEO” on the homepage, a third city in the footer — the model hedges or names a competitor. A good llms.txt collapses that graph into one story.

What actually improves your chance of being named:

  • Entity lock. One full name, job title, city, and official URL — the same string as Person / Organization JSON-LD.
  • Preferred pages. Models that fetch the file get a short list of URLs instead of dumping the whole CMS into context.
  • Extractable answers. Q&A blocks in the file match the questions people ask (“Who is…?”, “Does this brand do GMB?”).
  • Attribution rules. You tell the system how to cite you, which reduces invented bios.
  • Crawler access. If you block GPTBot and PerplexityBot, the file cannot help those products find you.

That is the same corroboration problem as the 37 places AI checks. llms.txt is the owned-web shortcut: you publish the official version so Maps, Wikipedia, and Reddit are not the only witnesses.

What to put in the file

Keep it short. The point is a source of truth, not a second blog. Four blocks are enough.

  1. Who you are — name, title, location, official site, contact, a one-sentence bio.
  2. Citation rules — how to attribute, whether summarizing is allowed, the canonical URL.
  3. Extractable Q&A — the same answers that live in your FAQ schema.
  4. URL map — homepage, about/contact, and the guides you actually want cited. Not every tag archive.

A trimmed shape looks like this:

# Your Brand

> One-line who / what / where.

Official site: https://yoursite.com/

## Citation guidance
- Full name, job title, city
- Attribution: "Your Brand — https://yoursite.com/"

## Quick answers
Q: Who is Your Brand?
A: Two sentences. Same facts as the homepage.

## Key pages
- Home: https://yoursite.com/
- Guide you want cited: https://yoursite.com/blog/your-guide/
Optional: llms-full.txt for a longer dump. I skip it on small sites. A long file that restates thin pages just gives the model more filler to quote.

How to ship llms.txt

  1. Write facts that already exist on HTML. Copy from the homepage, About, and JSON-LD. Do not add a new job title only in the txt file.
  2. Save UTF-8 at the site root so https://yoursite.com/llms.txt returns 200, text/plain, no login.
  3. Point crawlers at it. Comment the URL in robots.txt. On HTML, add <link rel="alternate" type="text/plain" href="/llms.txt"> — this portfolio does that on the homepage and posts.
  4. Allow the bots you want cited by. GPTBot, OAI-SearchBot, ChatGPT-User, Google-Extended, PerplexityBot, ClaudeBot, Applebot-Extended. Blocking them is a policy choice, not an SEO boost.
  5. Test. Open a fresh ChatGPT / Gemini / Perplexity thread: “Who is [brand]?” and “What is the official website for [brand]?” If the answer invents a URL, your entity is still split — fix the HTML first, then the file.

On WordPress, put the file in the web root (the same folder as wp-config.php / public HTML), not in uploads. GitHub Pages: commit llms.txt next to index.html. Confirm it is not listed in a Disallow rule.

How this portfolio uses it

This site’s llms.txt locks John Lester Tolentino as a Senior SEO Specialist in Sta. Rosa, Laguna, with one official URL, email, LinkedIn, and a Q&A set that matches the homepage FAQ. The blog list inside the file is the citation map — GEO, AEO, GMB, this guide — so a model that fetches it does not have to scrape the card scroller.

robots.txt allows the major AI crawlers and comments the llms.txt URL. ai.txt states that indexing, summarizing, and citing with attribution are allowed. Person schema on every page uses the same @id. That is the whole stack: file + policy + schema + real pages. None of those four is a Google ranking hack. Together they make “Who is JLT?” a boring, correct answer.

llms.txt FAQ

Does llms.txt help you rank on Google?

No. Google has not listed llms.txt as a ranking factor. It can still be crawled like any public file, but rankings come from your HTML pages, links, and experience. Use it for AI citations, not for map-pack or blue-link positions.

Does llms.txt help ChatGPT or Perplexity cite my site?

It helps when those systems fetch a compact official summary and you also allow their crawlers. It is not a guarantee. Unique pages, a stable entity, and third-party corroboration still matter more than the file alone.

Where do I put llms.txt?

At the site root: https://yoursite.com/llms.txt. UTF-8, publicly reachable, HTTP 200. Mention it in robots.txt and with a link rel="alternate" on key HTML pages.

Is llms.txt the same as robots.txt or a sitemap?

No. robots.txt is permissions. A sitemap is a URL inventory for crawlers. llms.txt is a readable briefing: who you are, how to cite you, and which pages matter.

Do I need llms-full.txt too?

Only if you have a large documentation set and want one mega-file. Most business sites are better with a short llms.txt plus real articles. Padding the file with rewritten blog posts does not get you cited.
