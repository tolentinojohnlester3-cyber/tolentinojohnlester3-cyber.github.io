How to disavow spam links on your site

To disavow spam links on your site, export backlinks from Google Search Console, keep only the spammy domains you cannot get removed, save a UTF-8 disavow.txt file with one URL per line or domain:example.com, then upload it at the Disavow links tool on a URL-prefix property. Google can take a few weeks to apply it. Most sites should not use this tool at all.

When you actually need a disavow

A disavow tells Google: ignore these inbound links when you rank my pages. It does not delete the links from the web. Google’s own help page is blunt: this is an advanced feature, and using it wrong can hurt Search performance.

Google says you should disavow only if both are true:

  1. You have a considerable number of spammy, artificial, or low-quality links pointing at your site, and
  2. Those links have caused a manual action, or likely will.

Skip the tool for random directory mentions, competitor “negative SEO” noise you cannot prove, or every referring domain with a low rating in a third-party crawler. Those tools over-flag. If an agency dumps 8,000 domains into a file because a DA score looked scary, they can disavow real citations you still want.

If the problem is a fake copy of your brand ranking in results, that is a different job — report the clone or misleading site. If rankings moved in a confirmed spam update, audit content and policy first using the August 2026 spam update notes. A disavow file is not a core-update recovery button.

Check Search Console → Manual actions before you touch the disavow tool. The message you want to match is usually “Unnatural links to your site.” No manual action and no paid-link scheme you built? Leave the tool closed.

Find the spam links

Start with Google’s own data, not a random “toxic score” export.

  1. Open Search Console → Links → Top linking sites (and Top linking pages if you need URL-level proof).
  2. Export the table. Google lets you download the Links report so you can edit it offline. Remove every row you do not want to disavow.
  3. Spot-check the worst hosts in a browser. Look for paid-link networks, spun articles with your exact-match anchor, hacked comment blocks, and sites that exist only to sell links.

Group by domain when the whole host is junk. Keep a single URL when the rest of that site is fine and only one page is a paid post.

PatternUsually disavow?
Private blog network, identical templates, sold “homepage links”Yes — usually domain:

Ask for removal first

Google’s order is: get the link off the other site, then disavow what remains. Email the webmaster, use their contact form, or file an abuse ticket if the page is hacked. Save the date and a screenshot. That paper trail matters if you later file a reconsideration request for a manual action.

Give them a reasonable window — a week or two, not an hour. Then move the stubborn hosts into the text file.

Build the disavow.txt file

Google only accepts a plain-text file encoded in UTF-8 or 7-bit ASCII, filename ending in .txt, max 100,000 lines and 2 MB. One URL or domain per line. You cannot disavow a folder such as example.com/en/.

Use Notepad, VS Code, or another editor that can save UTF-8 without a BOM if possible. Do not upload a Word doc or a Google Sheet export.

# Paid blog network — cannot get removed (Sept 2026)
domain:shadyseo.example
domain:pbns-for-sale.example

# Single toxic URL on an otherwise normal site
https://spam.example/paid-links.html
  • domain:shadyseo.example — ignore every URL on that host (and typically the obvious www variant as part of the host you listed).
  • A full https://… line — ignore that page only.
  • Lines starting with # — notes for you. Google ignores them.
A new upload replaces the entire list for that property. Download the current file from the disavow tool first, add the new rows, then re-upload the whole thing. If you upload a two-line file, you just wiped a thousand earlier disavows.

Upload it in Search Console

You must be a verified owner. The disavow tool does not support Domain properties (sc-domain:). Add and verify a URL-prefix property such as https://www.yoursite.com/ if you only have the domain property today.

  1. Open the Disavow links tool.
  2. Select the URL-prefix property that matches the live site (https, www vs non-www). Google applies the list to that property and its child properties. If you still have separate http and https properties, upload to each.
  3. Upload the .txt file. Confirm the warning. Google will show a count of domains and URLs.
  4. If the file has syntax errors, fix them and try again. The previous list stays until a clean file succeeds.

Official documentation: Disavow links to your site.

After you upload

  1. Wait. Google says it can take a few weeks as it recrawls and reprocesses pages. There is no progress bar.
  2. Do not expect the Links report to hide them. Disavowed links still show there. The report is a crawl log, not a “these still count” list.
  3. Manual action? After the disavow is in, submit a reconsideration request that explains what you removed, what you disavowed, and that you will not buy those links again.
  4. Need to undo everything? Open the same tool and choose Cancel disavowals. That also takes a few weeks to unwind.

Keep the .txt in git or a dated folder. Next quarter, append new junk hosts — do not start a blank file.

Disavow is not link building in reverse and it will not lift a site that lost visibility for thin content. Clean the links you actually bought or inherited, then go back to pages that deserve to rank — see what SEO is if you need that baseline.

Disavow spam links FAQ

How do I disavow spam links in Google Search Console?

Create a UTF-8 .txt file with one spam URL per line or domain:example.com, then upload it at search.google.com/search-console/disavow-links on a verified URL-prefix property. You must be an owner. A new file replaces the old list.

Should I disavow every low-quality backlink?

No. Google says most sites never need the tool. Use it for a large spam problem plus a manual action (or a clear paid-link scheme you cannot unwind). Random low ratings in a third-party audit are not enough.

Why can’t I see the disavow tool on my Domain property?

Google does not support Domain properties for disavow. Verify a URL-prefix property (https://yoursite.com/) and open the tool against that property.

How long does a disavow take to work?

Google says a few weeks, because it has to recrawl and reprocess. Manual-action recovery can take longer after you also file reconsideration.

Will disavowed links disappear from the Links report?

No. They stay visible. The disavow only asks ranking systems to ignore them.

Can I disavow a whole folder like /blog/spam/?

No. Google does not accept a subpath. Use domain: for the host or list each full URL.
