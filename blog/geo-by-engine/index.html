GEO by engine: how ChatGPT, Claude, Gemini, and Perplexity decide what to say

Generative engine optimization is not one ranking system. ChatGPT, Claude, Gemini, and Perplexity share a retrieve-then-cite loop, then split on index, crawler, and trust score. A page that wins Gemini can miss ChatGPT. Here is how each tool actually decides — and what I change on a site for each one.

Key takeaway

ChatGPT, Claude, Gemini, and Perplexity share a retrieve-then-cite loop, then split on index, crawler, and trust. Allow the search bots, write extractable facts, and test citations in all four — a Gemini win can still miss ChatGPT.

One question, four answers

Ask the same commercial question in four chat tools and you rarely get the same brands. That is not a glitch. Each assistant searches a different index, scores trust differently, and cites a different slice of the web.

The Machine Relations Index (82-day window ending 4 August 2026) measured 10,661 answer runs. Among the top 100 most-cited domains, 29 had engine gaps — cited by some tools, missing in others. Reddit sat at a 12.6% overall citation rate, almost entirely from Gemini and Perplexity. ChatGPT and Claude did not cite it at a measurable rate. Pairwise source overlap between engines has been measured as low as the teens. ChatGPT and Perplexity have shown about 11% domain overlap in some public citation studies.

That is why a single “GEO score” is a trap. The site-wide base still matters — original data, a locked entity, answer-first pages, schema, and llms.txt. After that, you optimize by engine. For the shared playbook, start with GEO strategies. This post is the split: how each model decides what to say.

GEO by engine means: keep one crawlable source of truth, then match the crawler, index, and extract style of each assistant. You do not write four sites. You write one site that four pipelines can parse.

The shared decision loop

Under the logos, the four tools run the same six steps. Differences live inside each step, not in a secret ranking formula.

  1. Prompt. The model rewrites your question into search queries. It almost never runs the raw string you typed.
  2. Retrieve. It pulls candidates from a partner index, its own crawl, Google Search, or a live fetch. Block the search crawler and you drop out here.
  3. Rank. Relevance, freshness, domain trust, and “can I parse this HTML?” beat classic domain authority. One study found traditional DA explained about 5% of citation behavior.
  4. Extract. Models prefer the first third of a page, short definition paragraphs, tables, and named stats. Semantic HTML tables have been associated with roughly 2.5× more citations than the same facts in prose.
  5. Generate. The model writes an answer from the extracts plus training memory. Vague pages get merged into a generic paragraph with no URL.
  6. Cite. Only a few sources make the footnote. ChatGPT is stingy. Perplexity shows numbered sources by default.

Most citation failures are retrieval or extract failures — the bot never saw you, or it saw a wall of marketing copy with no sentence it could quote. That sits on the same stack as SEO → AEO → GEO: if Google cannot crawl the URL, most AI pipelines will not either.

ChatGPT: search when it needs to

ChatGPT answers from training data until the question looks fresh, local, or comparative. Then it turns search on. OpenAI has said ChatGPT Search uses partner indexes (Bing is one) plus trusted feeds for weather, sports, stocks, and news. The model rewrites your prompt into targeted queries. It does not paste your sentence into a search box.

Three crawlers matter, and they are not interchangeable:

  • GPTBot — training. Disallow it if you do not want content in future models. That is a policy choice, not a ranking lever.
  • OAI-SearchBot — the index behind ChatGPT Search. OpenAI is explicit: sites that opt out will not appear in ChatGPT search answers.
  • ChatGPT-User — a live fetch when a person asks ChatGPT to read a URL right now.

ChatGPT cites less often than the other three. When it does cite, it leans on consensus pages: official sites, Wikipedia-style entity facts, news, and documentation that several sources already agree on. It is weak on Reddit. It is stronger when your name, city, and canonical URL match across the homepage, About, schema, and LinkedIn — the entity lock I cover in 37 places AI checks.

What I ship for ChatGPT: allow OAI-SearchBot and ChatGPT-User. Put a 40–60 word definition under the H2. Repeat the same bio facts in llms.txt. Do not hide the claim in a hero image. ChatGPT reads HTML, not pixels.

Claude: a tool it can refuse to call

Claude treats the web as a tool, not a default. With web search enabled, it decides each turn whether to search or answer from context. Anthropic’s search runs server-side, can loop for more queries, and returns automatic citations for pages it used. Claude also has a long context window, so when it does fetch you, it can read more of the page than a snippet-first engine.

Crawlers: ClaudeBot (training) and Claude-SearchBot (retrieval). Allow the search bot if you want to be citable. Claude’s public citation pattern favors long, well-structured documents with named evidence — docs, policy pages, research summaries, and editorial explainers — over forum threads. In the MRI data, Substack showed up for Claude; Reddit did not at a measurable rate.

Claude is the most likely of the four to hedge. That is a feature of how it is trained, not a bug in your page. If the claim is unsourced, Claude will often skip the brand instead of inventing a confident recommendation.

What I ship for Claude: allow Claude-SearchBot. Write the full argument on one URL (not a 300-word teaser). Name the author, date, and source of every number. Use descriptive H2s and tables. Claude rewards documents that look like a primary source, not a listicle remix.

Gemini: Google Search with extra steps

Gemini is the engine that still behaves most like SEO. Grounding with Google Search lets the model fan a question into several sub-queries, run them on Google’s index, then write an answer with URL citations. Google AI Mode uses the same idea. If you already rank for the query cluster, you are in the candidate set. If you do not, Gemini has little reason to invent you.

Google-Extended is a robots.txt token for Gemini training and grounding. It is not Googlebot. Disallowing Google-Extended does not remove you from classic Search. Allowing it is the GEO choice if you want Gemini to use the page as a source. Googlebot still handles rankings, AI Overviews, and AI Mode retrieval from the Search index.

Gemini and Google’s answer surfaces pull Reddit, YouTube, Maps, and reviews more than ChatGPT or Claude. Local businesses get a second door: a complete Google Business Profile. Schema you already ship for rich results — Organization, Person, FAQPage, LocalBusiness — is parsed by the same company that grounds Gemini. See types of structured data.

What I ship for Gemini: keep ranking in Google. Allow Google-Extended if Gemini visibility is the goal. Match NAP. Add FAQ and Article JSON-LD that repeats visible text. Treat AI Overviews and Gemini chat as cousins of AEO, not a separate website.

Perplexity: retrieve first, cite in public

Perplexity is a search product with a chat UI. It almost always retrieves. It shows numbered citations by default — often three or four pages. That makes it the easiest engine to see whether you won, and the noisiest competitor set, because forums, news, and fresh posts sit next to your money page.

PerplexityBot builds the answer index. Perplexity-User fetches a page when a person asks. Perplexity has said the user agent is not a training crawler. Blocking PerplexityBot is a direct citation cut. Freshness, extractable answers, and a clear H2 that matches the query matter more here than a 2023 cornerstone guide with no update date.

Perplexity overlaps Gemini on community sources (Reddit shows up) and overlaps classic SEO on domain trust. It is less consensus-driven than ChatGPT and less “Google rank first” than Gemini. A dated table with a short answer under the question heading is the page shape it extracts cleanly.

What I ship for Perplexity: allow PerplexityBot. Put dateModified on the page and in schema. Lead with the answer, then the table. Refresh stats when they age. Do not rely on a PDF or an image of a chart.

GEO playbook by engine

Do this once on every money page, then layer engine-specific checks.

Shared (all four)

  • One canonical name, title, city, and official URL on the page, in schema, and in llms.txt
  • A 40–60 word answer under the question H2
  • At least one dated, first-party stat or process count
  • Person + Article + FAQ JSON-LD that matches visible text
  • AI search crawlers allowed — not only the training bots

Then specialize

  • Claude — the long version of the argument, with named sources, on one crawlable URL.
  • Gemini — rankings, schema, Knowledge Graph consistency, and Google Business Profile if you are local.
  • Perplexity — freshness, tables, and an H2 that matches the live query.

Training crawlers (GPTBot, ClaudeBot) and search crawlers (OAI-SearchBot, Claude-SearchBot, PerplexityBot) are different jobs. Blocking training does not have to block citations. Blocking the search bot does.

How I test citations

I do not chase a fake #1 in ChatGPT. I keep a prompt set of 10 questions a customer would actually ask, then run them weekly in all four tools with search/browse on.

  1. Score each run: cited with URL / mentioned without URL / absent / competitor cited.
  2. Note which engine missed you. A Gemini miss is usually a ranking or GBP gap. A ChatGPT miss is often entity split or OAI-SearchBot blocked. A Perplexity miss is often a stale page. A Claude miss is often a thin, unsourced page.
  3. Fix that surface. Re-run the same prompt seven days later. Models refresh sources; one lucky cite is not a strategy.

GEO by engine FAQ

Do ChatGPT, Claude, Gemini, and Perplexity cite the same sites?

No. Overlap is limited. Reddit is a clear split: Gemini and Perplexity cite it heavily; ChatGPT and Claude largely do not. Optimize the shared page, then verify each engine separately.

Is ranking in Google enough for GEO?

It is the strongest input for Gemini and a useful prior for the others. It is not enough for ChatGPT Search if OAI-SearchBot is blocked, or for Perplexity if the page is stale and hard to extract.

Which crawler should I allow first?

If the goal is citations, allow the search agents: OAI-SearchBot, Claude-SearchBot, PerplexityBot, and keep Googlebot. Decide GPTBot, ClaudeBot, and Google-Extended as a training-policy choice.

Why does ChatGPT answer without a link?

It often answers from training memory and only cites when search ran and a page was clean enough to quote. Consensus entity pages get named; thin rewrites do not.

Does llms.txt make all four engines cite me?

No. It is a source map, not a ranking factor in Google and not a citation guarantee in chat tools. Pair it with crawlable pages, schema, and allowed search crawlers.

Should I write four different articles?

No. Write one canonical guide. Change extractability (definition, table, date, entity) so four pipelines can use it. Duplicate posts for each brand of chatbot waste crawl budget.
