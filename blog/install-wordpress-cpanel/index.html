How to install WordPress in cPanel (step-by-step guide)

Most shared and reseller hosting plans include cPanel with Softaculous — a one-click installer for WordPress. This guide uses the current cPanel Jupiter dashboard (sidebar navigation, tool cards, and Search Tools bar) and walks you from login to a live site with watermarked screenshots at every step.

Before you start

You need four things ready before clicking Install:

  • cPanel login URL — usually https://yourdomain.com:2083 or a link from your host’s welcome email
  • Username and password — the cPanel credentials your hosting provider sent you
  • A domain pointed to the server — the site must resolve to your hosting account (nameservers or A record set)
  • An admin email — use a real address; WordPress sends password resets and updates here
Tip: If your host uses a different auto-installer (Installatron, Fantastico, or a custom “WordPress Manager”), the labels change slightly but the flow is the same: pick WordPress → choose domain → set admin details → install.

Step 1 — Log in to cPanel

Open your cPanel URL in a browser. Enter your username and password, then click Log in.

If two-factor authentication is enabled, complete that step. You should land on the modern Jupiter dashboard — a left sidebar, a Search Tools bar at the top, and grouped tool cards (Files, Databases, Domains, Email, Software).

Step 2 — Open Softaculous Apps Installer

On the Jupiter home screen, type Softaculous in the Search Tools bar — or open the Software category and click Softaculous Apps Installer.

Some hosts also pin WordPress as a shortcut on the dashboard. Any of those paths opens the same installer.

Step 3 — Select WordPress

Inside Softaculous, open the Top Scripts or search bar and click WordPress. Review the version shown — install the latest stable release unless your host recommends otherwise.

Click the blue Install Now button (not “Demo” or “Import”).

Step 4 — Configure install settings

Softaculous shows a form. Fill in the fields below carefully — mistakes here are the most common cause of wrong URLs or lost admin access.

Software setup

  • Choose Domain — pick the domain where WordPress should live. Use a subdomain (e.g. blog.yoursite.com) if you are testing first.
  • In Directory — leave blank to install at the root (yoursite.com). Enter blog only if you want yoursite.com/blog.
  • Site Name — your site title (changeable later in Settings → General).
  • Site Description — optional tagline; many SEO setups leave this empty at first.

Admin account

  • Admin Username — avoid admin. Use something unique.
  • Admin Password — use a long, random password and save it in a password manager.
  • Admin Email — must be valid; you need it for recovery.

Advanced options (optional)

  • Select Language — choose your content language.
  • Limit Login Attempts — enable if offered; reduces brute-force attacks.
  • Backup location — some hosts let you schedule Softaculous backups; useful before major updates.

Scroll to the bottom and click Install. Softaculous creates the MySQL database, uploads WordPress files, and runs the setup script — usually under one minute.

Step 5 — Finish and open wp-admin

When installation completes, Softaculous shows a success message with two important links:

  • Administrative URL — your login page, typically https://yourdomain.com/wp-admin/
  • Visit Website — the public front end

Log in with the admin username and password you set in Step 4. You are now inside the WordPress dashboard.

Save these details now: admin URL, username, password, and the database name Softaculous created (visible under installation details). You will need them for migrations, backups, and troubleshooting.

After install checklist

WordPress is live, but a few minutes of setup saves weeks of SEO and security headaches later:

  1. Force HTTPS — in cPanel, use SSL/TLS Status or AutoSSL, then set WordPress Address and Site Address to https:// under Settings → General.
  2. Permalinks — Settings → Permalinks → choose Post name for clean URLs (/blog-post-title/).
  3. Delete default content — remove the “Hello world!” post and sample page if you do not need them.
  4. Update timezone — Settings → General → set your city so scheduled posts publish on time.
  5. Install essentials — caching plugin, security plugin, and a backup plugin (or use host backups).
  6. Discourage search engines — only while building; uncheck Settings → Reading → “Discourage search engines” before launch.

Once the site is public, apply basic SEO: unique titles, XML sitemap, and fast hosting. For the full picture of how search fits into your stack, read layers of SEO and what is SEO.

Manual install (when Softaculous is unavailable)

If your plan lacks Softaculous:

  1. Create a MySQL database and user in cPanel → MySQL Database Wizard.
  2. Download WordPress from wordpress.org.
  3. Upload files via File Manager or FTP to public_html (or your domain folder).
  4. Visit your domain — WordPress runs the famous five-minute install and asks for database details.

Softaculous is faster and less error-prone for beginners. Manual install gives more control when you need custom folder layouts or multisite setups.

FAQ

How long does WordPress installation take in cPanel?

With Softaculous, usually 30 seconds to 2 minutes. Manual upload and database setup can take 10–20 minutes if you are new to FTP.

Can I install WordPress on a subdomain?

Yes. Create the subdomain in cPanel → Domains → Subdomains first, then choose that subdomain in Softaculous under Choose Domain.

What is the difference between public_html and a subfolder?

public_html is the web root for your primary domain. A subfolder like public_html/blog serves WordPress at yoursite.com/blog. Leave In Directory blank for root installs.

Do I need to create a database manually with Softaculous?

No. Softaculous creates the database and user automatically and writes credentials to wp-config.php for you.

I forgot my WordPress admin password — what now?

Use “Lost your password?” on the wp-admin login screen, or reset via phpMyAdmin, or through Softaculous’s “Edit Details” for that installation.
