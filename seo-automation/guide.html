How to use the Free SEO Automation Tool

Set up once in your browser, then use it every week to research topics, draft outlines, approve articles, and plan publishing — without a subscription.

1. What you need

You needWhy
A modern browserChrome, Edge, Firefox, or Safari. The tool runs locally.
Your website addressUsed in project settings and draft outlines.
Optional keyword CSVAhrefs/Semrush-style export improves topic scoring context.
Optional Search Console CSVFor the monthly snapshot and query list.
Your CMS (WordPress, etc.)You publish approved drafts yourself. This free tool does not push live.
Private by default. Projects, drafts, and reports stay in this browser’s storage. Nothing is sent to a server.

2. Start in 2 minutes

  1. Open the free tool.
  2. Go to Project settings and save your website name and URL.
  3. Optional: import keywords on Keyword research.
  4. On Topic ideas, approve a starter topic (or add your own).
  5. Click ▶ Run free automation to create a starter draft.
  6. Open Review and approve, edit facts, then approve.
  7. Click Run again to schedule it on the content calendar.

3. What the Run button does

Waiting itemRun result
Approved topics without a draftBuilds a starter outline draft
Approved drafts not yet scheduledAdds them to the calendar
Scheduled articles whose date has arrivedMarks published locally and prepares social posts

Nothing goes to your website automatically. You copy the approved draft into WordPress (or any CMS) when you are ready.

6. What this free tool does not do

  • It does not call Claude or any paid AI API.
  • It does not publish to WordPress/Novamira automatically.
  • It does not promise rankings.
  • It does not sync across devices unless you move a backup JSON file yourself.

7. Backup and privacy

Use Backup and move → Download my backup before clearing browser data, switching computers, or private-window sessions.

Clearing site data deletes the workspace. Restoring a backup JSON brings it back.
